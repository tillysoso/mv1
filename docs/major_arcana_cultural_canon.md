# Major Arcana Cultural Canon

This document captures the full 22-card Major Arcana reference system in a strict cultural-canon format. It uses one film, one hero scene, one song, one short hero lyric, one historical event only where the fit is widely recognized, one museum-quality artwork with a link, one attributable quote with source, and one brief explanation for why the selection unlocks the card.[cite:35][cite:48][cite:16]

## Notes

Historical-event cells are intentionally left blank where no widely recognized event cleanly explained the card better than the other references would.[cite:35]

Artwork links are provided as museum or institution pages where possible, with a few institution-level collection pages used when a stable direct object page was not available in the earlier source set.[cite:16]
